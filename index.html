Lessons

Lesson 1: Your First Web Page

HTML, which stands for "HyperText Markup Language," is the foundational language of the web. It's used to create and structure websites. By utilizing HTML tags, we can define the appearance and layout of a website. With a good grasp of these tags and their proper usage, creating beautiful websites becomes straightforward and efficient!
Every HTML page starts with a basic structure. Here is a small example:

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
  </body>
</html>

Save the file as index.html and open it in your browser. You should see this output:

Hello, World!

To refresh the page after you make a change, press Ctrl + R (or Cmd + R on Mac).

Extra Note

The lang attribute helps screen readers pick the right voice.

Lesson 2: Text and Links

Use headings for titles, p for paragraphs, and a for links.

<h2>My Hobbies</h2>
<p>I like <strong>reading</strong> and <em>coding</em>.</p>
<a href="https://example.com" target="_blank">Visit Example</a>

Sample output in the browser:

My Hobbies
I like reading and coding.
Visit Example

Remember: always write a clear link text, not just "click here".

Lesson 3: Lists and Tables

Lists group related items. Tables show data in rows and columns.

Common list tags
ul
An unordered (bullet) list.
ol
An ordered (numbered) list.
li
One item inside a list.

Lesson 4: Forms

Forms collect information from users. The steps to make one:

  1. Add a form tag.
  2. Add a label and an input for each field.
  3. Add a button to send the form.

Note: Without JavaScript or a server, a form cannot save data. This course only teaches the structure.
